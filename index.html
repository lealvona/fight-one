Fight One

An original browser fighting game, evolved in public. Every major version stays playable below - same engine lineage, bigger ambitions each time. Flow is the weapon.

Run locally: npm start then open http://127.0.0.1:4173/ - no install step, Three.js is vendored.
Telemetry: all versions log to game.log through the local server; events mirror to the browser console.
Quick links: append ?autostart=1&p=daichi&e=lobo to any 3D version to skip the select screen.
